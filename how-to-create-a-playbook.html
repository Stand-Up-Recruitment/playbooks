Overview

What is a Playbook?

The purpose, structure, and format of Stand Up Recruitment playbooks — and why they exist.

What is it?
A Stand Up Recruitment Playbook is a self-contained HTML file that gives any team member clear, video-backed instructions for every key business process. It opens in any browser — no login, no internet, no special software required.
How it is structured
Each playbook contains a searchable dashboard of tiles. Every tile covers one process and has four tabs:

Overview — Purpose, context, and key information
Watch — Embedded screen recording of the process
Steps — Step-by-step instructions built from the transcript
Quiz — Comprehension check (where included)
Existing playbooks at Stand Up
Admin & Ops — admin-ops-playbook-final.html
All playbook files live in the same OneDrive folder as the videos:
Documents - Stand Up Recruitment HQ / ACCOUNTS & ADMIN / PLAYBOOK VIDEOS / NEW Videos
No internet needed. Playbooks are fully self-contained HTML files. Videos are linked from the same OneDrive folder on your computer — as long as the folder is synced, everything works offline.
Golden Rules
1
One video = one tile. Keep each tile focused on a single process. If a process is complex, split it into Part 1 / Part 2 as separate tiles.
2
Always say the tile name at the start of the recording. This gives Claude the context it needs to build accurate content.
3
Filenames must match exactly. The .mp4 and .docx must share the identical base name. Even a single character difference will break the video.
4
Always say "no changes to structure or format" in your Claude prompt. This keeps all tiles visually consistent.
5
Hard refresh after every update. Press Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac) — otherwise the browser shows the old cached version.
6
Never manually edit the HTML file. Always ask Claude. Manual edits can break the div structure and cause navigation failures.
If something looks broken after an update — ask Claude to restore the previous backup. Claude creates a numbered .bak.html file before every change (e.g. admin-ops-playbook-final.bak10.html).
Step 1

Record in Microsoft Teams

How to screen record a process in Microsoft Teams with transcription — the foundation of every playbook tile.

Why Teams?
Microsoft Teams automatically generates a transcript (.docx) alongside the screen recording. This transcript is what Claude reads to build all the written content in the tile — Overview, Steps, and Quiz. Better narration = better tile content.
Before you start recording
  • Know exactly what process you are recording — do a practice run if unsure
  • Close irrelevant browser tabs and applications
  • Use a quiet environment so transcription accuracy is high
  • Speak clearly and narrate every action as you perform it
  • Start by stating the tile number and title clearly (e.g. "Hi, in this video I'm walking through 2.2.4 — how to monitor subscriptions monthly.")
Ideal recording length
Aim for 3–10 minutes per tile. Too short means not enough content. Too long is hard to watch. For complex processes, split into Part 1 / Part 2.
Critical: You must start both Recording AND Transcription. If transcription is not started, no .docx file will be generated and Claude cannot build the tile content.
How to Record with Transcription
1
Open Microsoft Teams → click Meet Now to start an instant meeting (no participants needed)
2
Click Share Screen → select the window or application you want to record
3
Click the ⋯ (three dots) in the meeting toolbar → select Start Recording
4
Immediately after: click ⋯ again → select Start Transcription
5
State the tile number and title, then narrate clearly as you perform the process — describe every click, every field, every decision
6
When finished: ⋯ → Stop Recording, then ⋯ → Stop Transcription
7
End the meeting. Teams will process the files — this may take a few minutes
8
Files will appear in the Teams meeting chat as attachments, or in OneDrive → My Files → Recordings
Step 2

Export the Video & Transcript

How to download the .mp4 recording and .docx transcript from Teams or OneDrive.

Two files you need
1. Video (.mp4) — played in the Watch tab of the tile

2. Transcript (.docx) — uploaded to Claude so it can build all written content (Overview, Steps, Quiz)
Where to find them
Option A: In the Teams meeting chat as attachments after the meeting ends

Option B: In OneDrive → My Files → Recordings
Check transcript quality before uploading to Claude. Open the .docx and skim it — fix any obvious transcription errors (e.g. misheard technical terms, system names, amounts). This directly improves the quality of the tile content Claude generates.
Download from Teams Chat
1
Go to the Teams meeting chat where the recording was made
2
Hover over the recording attachment → click the download icon → save the .mp4 file
3
Hover over the transcript attachment → click download → save the .docx file
Alternative — Download from OneDrive
1
Open OneDrive → My Files → Recordings
2
Find the recording — right-click → Download → save as .mp4
3
Find the matching transcript (same name, .docx extension) → download
Once downloaded, rename both files before saving to the playbook folder — see Step 3 for the naming format.
Step 3

Name & Save Your Files

The correct naming format and folder location — essential for videos to play in the playbook.

Why naming matters
The playbook HTML file references videos by their exact filename. If the filename doesn't match what Claude put in the HTML, the video will not load in the Watch tab.
Naming format
[Section number] [Title].mp4
[Section number] [Title].docx

Examples:
2.2.4 How to monitor subscriptions monthly.mp4
2.2.4 How to monitor subscriptions monthly.docx

3.1.14 HR Consultations - Peninsula.mp4
3.1.14 HR Consultations - Peninsula.docx
Folder location — save to your division's folder

Both files must share the exact same base name — only the extension differs (.mp4 vs .docx). Confirm the tile number and title with Nihanga before naming if creating a brand new tile.
Name & Save Process
1
Confirm the correct tile number and title. For new tiles, check with Nihanga before naming — this avoids having to rename later.
2
Rename the video file using the format: [Number] [Title].mp4
3
Rename the transcript using the same base name: [Number] [Title].docx
4
Save both files to:
OneDrive → Documents - Stand Up Recruitment HQ → ACCOUNTS & ADMIN → PLAYBOOK VIDEOS → NEW Videos
5
Confirm both files are visible in the folder before prompting Claude. If OneDrive is still syncing, wait until the sync is complete.
Do not use special characters other than spaces, hyphens, and dots in filenames. Brackets, slashes, or ampersands will break the video path.
Step 4

Build the Tile with Claude

How to give Claude the right instructions to create or update a playbook tile from your transcript.

What Claude does
Claude reads your .docx transcript, extracts all key steps and information, and builds a fully formatted HTML module with all tabs — then injects it directly into the playbook HTML file and saves it. You don't need to touch any code.
Two scenarios
Updating an existing tile — the tile already exists with placeholder or old content. Claude replaces only that tile with new content from your transcript. Everything else stays exactly the same.

Creating a brand new tile — the tile doesn't exist yet. Claude adds a new dashboard card in the right section AND adds the new module in the correct position in the HTML file.
Module ID — what it is
Every tile has an internal ID. It's simply the tile number with all dots removed:

2.2.4 → m224   3.1.8 → m318   3.1.14 → m3114   2.2.21 → m2221

Always tell Claude the module ID in your prompt so it knows which tile to work on.
Tip: Use the Cowork mode desktop app for all playbook updates — it gives Claude direct access to your OneDrive folder where the files live. See the Prompt Library tile for copy-paste prompts for every scenario.
The build process
1
Confirm both the .mp4 and .docx are correctly named and saved in the playbook folder
2
Open Claude Cowork mode (desktop app) and make sure the playbook folder is connected
3
Go to the Prompt Library tile in this playbook and copy the right prompt for your scenario (update, create, delete, fix, etc.)
4
Fill in the tile number, title, and module ID in the prompt, then send it to Claude
5
Claude will: read the transcript → build the content → update the HTML file → confirm div balance (open tags = close tags)
6
Claude confirms it's done. Open the playbook HTML file, hard refresh (Ctrl+Shift+R), and review
If Claude reports unequal div counts (e.g. 450 open / 448 close) — do not accept the file. Ask Claude to investigate and fix the imbalance before saving.
Step 5

Review & Iterate

How to test every part of a new or updated tile and request precise corrections from Claude.

Why review matters
Claude builds content from auto-generated transcripts. Occasionally a step, figure, or detail needs a tweak — especially if something was shown on screen but not clearly stated in the recording. A quick review before sharing with the team prevents mistakes from being embedded in the playbook.
What to check
  • Dashboard card — title and description accurate and readable?
  • Open tile — all tabs visible and clickable?
  • Overview tab — key points accurate and clear?
  • Watch tab — video plays without errors?
  • Steps tab — all steps present, in correct order, with correct details?
  • Quiz tab — answers register, Check Answers marks correctly?
  • Back button — returns to dashboard?
  • Search — tile appears when you search a keyword?
Hard refresh is required every time after Claude updates the file. Press Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac). The browser caches the old version and will show the wrong content without this.
Review Checklist
1
Open the playbook HTML file in Chrome
2
Hard refresh: Ctrl+Shift+R (Windows) / Cmd+Shift+R (Mac)
3
Use the search bar to find the new tile — confirm it appears in the dashboard
4
Click the tile → confirm all tabs are present and clicking between them works
5
Watch tab: press play → video loads and plays from the correct file
6
Steps tab: read all steps → note anything missing, incorrect, or out of order
7
Quiz tab (if present): select answers → click Check Answers → confirms correct/incorrect
8
Click ← Back → returns to dashboard
Requesting a fix from Claude
1
Be specific — tell Claude exactly what needs changing. Include: tile name, tab name, step number or section, and the correct text. E.g. "In tile 3.1.8 NPP Process, Steps tab, Step 4 — the amount should be $13,500 not $7,200."
2
Claude makes the targeted change and saves → hard refresh → re-check
3
Repeat until the tile is accurate. Claude creates a new backup before each change, so nothing is ever permanently lost.
Never manually edit the HTML file unless you are experienced with HTML. Always ask Claude — even small manual edits can break div balance and cause the whole navigation to stop working.
